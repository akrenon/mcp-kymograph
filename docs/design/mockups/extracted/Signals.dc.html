What the server sends that a model could read as instruction

Every run, in both modes and with or without a scenario, reads the server’s side and writes down where content is addressed at a model rather than at a person. Each check is a named signal with a stable ID. An observation says where something sat and what shape it had — never a severity, never a verdict.
